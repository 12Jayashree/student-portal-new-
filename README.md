# 🎓 Student Portal

## 📌 About the Project

Student Portal is a simple web-based application designed to help students access their academic information in one place.

## ✨ Features

- 🔐 Student Login
- 🏠 Home Page
- 📅 Attendance Details
- 📚 Course Details
- 📊 CGPA Details
- 🔗 Easy Page Navigation
- 📱 Responsive Design

## 🛠️ Technologies Used

- HTML5
- CSS3
- Bootstrap 5
- JavaScript

## 📂 Files

- `login.html` – Login Page
- `index.html` – Home Page
- `attendance.html` – Attendance Details
- `courses.html` – Course Details
- `cgpa.html` – CGPA Details
- `style.css` – Styling

## 🚀 How to Run

1. Download or clone the project.
2. Open the folder in VS Code.
3. Open `login.html`.
4. Run it in a web browser.
5. Enter the demo login details.
6. Explore the Student Portal.

## 🎯 Objective

To develop a simple and user-friendly student portal for managing and viewing academic information.
